When users call `xrspatial.reproject.reproject`, integer `xarray.DataArray` rasters must preserve their source integer dtype when the requested output grid or output chunks do not overlap the source footprint. For dask-backed integer inputs, `reproject(...).dtype` and `reproject(...).compute().dtype` must both remain the source dtype, and empty chunks must be filled with the DataArray's resolved `nodata` value. The eager numpy path must also return an integer DataArray filled with resolved `nodata` when the output grid has no overlap. Floating-point inputs must keep the existing floating-point empty-fill behavior, including `float64` for that empty-fill path.
