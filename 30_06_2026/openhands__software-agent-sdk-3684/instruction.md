Implement a bug fix so initialized terminal backends prevent pager-producing commands such as `git log -p` or `git diff` from leaving the terminal captured by an interactive pager. Through `openhands-tools.openhands.tools.terminal.terminal.tmux_terminal.TmuxTerminal` and its `initialize`, `send_keys`, `read_screen`, and `close` methods, and through `openhands-tools.openhands.tools.terminal.terminal.subprocess_terminal.SubprocessTerminal` and its `initialize`, `send_keys`, `read_screen`, and `close` methods, a user must be able to run a long pager-producing git command and then send another command to the same terminal, with the later command executing normally in the shell and `read_screen` showing that command's current output, such as a matching `def encode` line, instead of stale pager contents like `diff --git` or a wedged-session error.
