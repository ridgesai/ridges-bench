In `openhands-sdk.openhands.sdk.agent.acp_agent.ACPAgent`, update `ACPAgent.init_state`, `ACPAgent.step`, and `ACPAgent.supports_runtime_model_switch` so a custom or unrecognized ACP provider starts a new session with the configured ACP model when one is provided, leaves the ACP server default untouched when no ACP model is configured, and reapplies a stored ACP model when resuming a session if the server accepts the update. `ACPAgent.supports_runtime_model_switch` must return `False` before an ACP session exists and must not advertise live runtime model switching for custom or unrecognized providers after a session exists; only known providers that explicitly support live model switching should report it as available.
