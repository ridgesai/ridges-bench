Update datamodel_code_generator.parser.jsonschema.JsonSchemaParser so schemas that express enums as oneOf or anyOf collections of const alternatives are exposed as enum-compatible generated data types/models rather than plain primitive strings or primitive unions. Through JsonSchemaParser.parse_raw, JsonSchemaParser.parse_item, JsonSchemaParser.parse_root_type, JsonSchemaParser.parse_enum, and JsonSchemaParser.parse_enum_as_literal, a root schema or property using this form must preserve every const value as an enum member value, such as Frontend and Server-side, and nullable combined const-enum schemas must remain nullable in the resulting enum representation.
