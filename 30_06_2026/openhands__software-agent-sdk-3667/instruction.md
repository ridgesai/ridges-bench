In openhands-sdk.openhands.sdk.agent.acp_agent, ensure ACPAgent exposes ACPAgent.init_state and ACPAgent.close and that session initialization forwards remote MCP server authentication as ACP-compatible HTTP headers. When a remote MCP server configuration has a string auth token and no explicit Authorization header, the ACP MCP server representation must include Authorization: Bearer <token>. When both auth and headers.Authorization are configured, the explicit Authorization header value must be preserved and not replaced. Non-Authorization headers configured in headers must also be forwarded unchanged by name and value as ACP HTTP headers.
